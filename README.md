## 🚀 Main Projects

### 🏭 Aerospace Production Flow Optimization

- Analyzed an aerospace manufacturing production flow
- Identified bottlenecks, waiting times, and non-value-added activities
- Monitored productivity, efficiency, lead time, and process performance
- Applied **DMAIC, VSM, Kaizen, Ishikawa, 5 Why, and continuous improvement methods**
- Explored opportunities for improving production visibility and digital traceability

---

### 💻 Industrial Digital Traceability Platform

- Designed and developed a **MES-oriented web platform** for industrial traceability
- Built the backend using **Python and Django**
- Managed production data with **PostgreSQL**
- Containerized the application using **Docker**
- Used **Nginx** for the deployment architecture
- Structured the monitoring of production operations, batches, and process data

**Tech:** Python · Django · PostgreSQL · Docker · Nginx · REST API · Linux

---

### 🔌 UAV Embedded Control & Supervision System

- Developed a client-server architecture for remote control and supervision of an onboard UAV computer
- Worked with **Raspberry Pi**, sensors, GPS, IMU, sonar, and camera systems
- Implemented telemetry and network communication using **MQTT and TCP/IP**
- Worked in a Linux-based embedded environment
- Used **Python, C/C++, Bash, Git, and GitLab**

**Tech:** Linux · Raspberry Pi · Python · C/C++ · MQTT · TCP/IP · GitLab · Embedded Systems
